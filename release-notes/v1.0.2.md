First public multi-platform release of **PasteSuiteAI** — instant plain-text pasting, AI dictation, and AI text transforms in any app. Includes a 7-day unlimited trial; non-AI features stay free forever.

## Downloads

| Platform | File |
|---|---|
| **Windows 10 / 11** (64-bit) — **stable**, signed installer | `PasteSuiteAI_1.0.2_x64-setup.exe` |
| **macOS** (Apple Silicon, M1+) — **early beta**, ⚠️ **UNSIGNED** build | `PasteSuiteAI_1.0.2_aarch64.dmg` |
| **Linux** (x86-64) — **early beta**, portable AppImage | `PasteSuiteAI_1.0.2_amd64.AppImage` |
| **Debian / Ubuntu** (x86-64) — **early beta**, native package | `PasteSuiteAI_1.0.2_amd64.deb` |

## Platform notes

- **Windows (stable)**: Digitally signed by Keynaptic GmbH. A one-time SmartScreen prompt may appear while our publisher reputation is still building — click *More info → Run anyway*. [Illustrated guide](https://pastesuiteai.com/install-help)
- **macOS (early beta)**: ⚠️ This build is **unsigned and not notarized** (Apple Developer signing is in progress). macOS blocks the first launch — allow it via *System Settings → Privacy & Security → Open Anyway*. Full steps in the [README](https://github.com/mcaonline/pastesuiteai-releases#installing-on-macos-early-beta-unsigned-build).
- **Linux (early beta)**: Built and tested against X11; on Wayland some global-hotkey features may be limited. AppImage: `chmod +x` and run. Deb: `sudo apt install ./PasteSuiteAI_1.0.2_amd64.deb`.

Install guides for all platforms: [README](https://github.com/mcaonline/pastesuiteai-releases#readme) · Website: [pastesuiteai.com](https://pastesuiteai.com/)
